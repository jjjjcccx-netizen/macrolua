# series.md: "의지 탓 아니에요" 10편

흐름: 마음(1-2) → 원리(3) → 시스템(4-5) → 운동 고르기(6) → 식단 도구(7) → 몸 교정(8-9) → 총정리(10)
주 2편씩 5주. 각 편 끝에 다음 편 예고를 넣어서 다음 편이 궁금하게 만듦.
근거: voice.md 입장, 이미 확인한 논문 2개, swipe.md에서 터진 형식. ✔ 표시는 본인 방식인지 확인할 곳.

## 템플릿 3개 (매번 고르기만 함)

- **A 글자카드 몽타주** (말 없음, 15~20초): 첫 화면 훅 → 번호 카드 1~2초씩 → 마무리 한 줄. 일상·운동 장면 아무거나 + 글자.
- **B 얼굴 보고 말하기** (25~35초): 훅 → 반전 → 이유 2~3개 → 처방 → 예고 → 요청. 차 안이나 집에서 정면.
- **C 동작 시연** (30~40초): 고민 질문 → 동작 3~4개, 동작마다 각도 바꿈 → 예고 → 요청.

## 생각 안 하고 만드는 규칙

1. 고민은 ✔ 칸에만. 나머지는 고치지 않고 그대로 찍기.
2. 촬영은 한 번에 몰아서: B 템플릿 5편(1·3·4·6·7)을 같은 옷, 같은 장소에서 하루에 찍기. A 템플릿 영상은 평소 일상을 찍어 둔 것으로 채우기.
3. 한 편에 20분 타이머. 다시 찍는 건 2번까지.
4. 편집 순서는 매번 같게: 훅 자막 → 본문 자막 → 컷마다 장면 바꾸기 → 끝 화면 "다음 편 ▶".
5. 숫자와 사례는 지어내지 않음. 모르면 그 줄을 빼고 찍기.
