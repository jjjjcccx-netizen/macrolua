# instagram

Instagram agent skill(https://github.com/Jakeschincariol/instagram-agent-skill)용 내 파일입니다.

- `voice.md` 내 말투 (본인 캡션·대본 3개에서 정리, `(확인 필요)` 칸은 아직 비어 있음)
- `plan.md` 이번 주 계획 (릴스 2개 + 유튜브 롱폼 1개)
- `log.md` 확정한 대본 기록
- `swipe.md` 경쟁 계정 릴스 분석 (/ig-viral, 2026-10-20)
- `restore.sh` 새 세션에서 스킬 13개 설치 + 위 파일을 `~/.claude/instagram/`에 복원

새 세션에서: `bash instagram/restore.sh` 를 실행하거나 "instagram/restore.sh 실행해 줘"라고 말하면 됩니다.
스킬이 바로 안 보이면 세션을 한 번 더 새로 여세요.
